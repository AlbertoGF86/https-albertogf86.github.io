Audio Post-Production Automation Consultant

Automated cleanup, processing and delivery pipeline for dubbing studios, audiovisual agencies and recording studios. The system classifies incoming files, separates sources, normalises to each destination standard and runs automatic quality control. Senior Sound Technician expertise embedded in every parameter.

Challenge
Post-production studios were processing audio files manually — no consistent loudness standards across deliverables, no automated QC, and 80% of time spent on repetitive technical tasks.
Solution
Automated processing pipeline: ingest → source separation via Lalal.ai → Auphonic normalization per destination standard (Broadcast / Streaming / Dubbing) → FFmpeg QC → Telegram delivery report.
Result
80% reduction in manual processing time. 100% consistent technical output per file. Zero loudness or True Peak errors on delivery since implementation.

Pipeline de procesado
01
Ingest y clasificación

MakeGoogle DriveGoogle Sheets
02
Separación de fuentes
Lalal.ai API separa voz, ruido de fondo y música en stems independientes. Limpiar cada elemento por separado da resultados significativamente mejores que limpiar el mix completo.

Auphonic aplica noise reduction, hum removal y de-essing. Loudness ajustado según destino: Broadcast −23 LUFS · Streaming −16 LUFS · YouTube −14 LUFS · Doblaje −18 LUFS + True Peak −1 dBTP.

04
Control de calidad automatizado
FFmpeg webhook verifica LUFS final, True Peak y duración vs original. Si el archivo no pasa el QC, alerta inmediata vía Telegram con el motivo específico.

Por qué un Técnico Superior de Sonido
🎚️
Parámetros de loudness con criterio profesional
EBU R128, −16 LUFS y −14 LUFS no son lo mismo. Cada destino tiene su estándar. El sistema aplica el correcto automáticamente para broadcast, streaming, doblaje o YouTube.
🔬
Separación de fuentes antes de limpiar
Limpiar el mix completo da peor resultado que limpiar la voz sola y recombinar. Este orden de operaciones solo lo define alguien que entiende el audio a nivel técnico.
✅
QC con métricas reales
El sistema verifica True Peak, LUFS integrado y duración. Son las mismas métricas que piden broadcasters y distribuidoras en sus especificaciones técnicas de entrega.
🤝
Conversación técnica de igual a igual
Phase coherence, artifacts del de-noiser, limitaciones del compresor en ciertos materiales. Con el técnico del estudio se habla de tú a tú. Eso genera confianza y reduce fricción.
